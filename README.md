# 📱 JFTech

Sistema web desenvolvido para apresentação e divulgação de produtos de uma loja de acessórios para celulares. O projeto possui uma interface moderna, navegação intuitiva e catálogo organizado por categorias, proporcionando uma melhor experiência ao usuário.

## 🚀 Funcionalidades

- Exibição de produtos em catálogo.
- Organização dos produtos por categorias.
- Barra de pesquisa para localizar produtos.
- Interface responsiva para computadores e dispositivos móveis.
- Botão para consulta de disponibilidade via WhatsApp.

## 🛠️ Tecnologias utilizadas

- React
- JavaScript
- HTML5
- CSS3
- Vite

## 🎯 Objetivo

O projeto foi desenvolvido com o objetivo de praticar o desenvolvimento de aplicações web utilizando React, criando uma interface moderna para divulgação de produtos e aprimorando conhecimentos em componentização, estilização e experiência do usuário.

## 💻 Funcionalidades da interface

- Página inicial com destaque para os produtos.
- Catálogo organizado por categorias.
- Pesquisa dinâmica de produtos.
- Layout responsivo.
- Navegação simples e intuitiva.

## 📚 Aprendizados

Durante o desenvolvimento foram aplicados conceitos como:

- Desenvolvimento Front-end com React.
- Componentização.
- Manipulação de estados.
- Organização de projetos utilizando Vite.
- Responsividade.
- Boas práticas de desenvolvimento web.
